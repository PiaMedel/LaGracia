Importar datos

Paso 1: cargar el catálogo (una vez, o cuando cambie). Paso 2: cada semana (o día), subir el Excel base de movimientos.

1. Catálogo (Excel): productos, materias primas y recetas

Si subes el mismo archivo corregido, lo existente se actualiza (no se duplica). Si cargaste algo mal y quieres partir de cero, usa "Zona de peligro" más abajo.

Descargar plantilla de catálogo

2. Excel base de movimientos (diario o semanal)

Un solo archivo con 4 hojas: Ingreso de productos (descuenta materias primas según receta), Compras materias primas, Ventas y Mermas y regalos (merma, regalo o muestra). Se descarga ya con tus productos y materias primas: solo escribes cantidades. Si una fila falla, no se carga nada.
